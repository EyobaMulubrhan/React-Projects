# React learning & practice projects

Welcome to my React practice repository! This collection contains **five distinct web applications** built from scratch. The primary goal of this repository is to document my journey in mastering **React core concepts**, structural component patterns, state management, and API integrations.

---

## Project showcase

### 1.Counter application (`01-counter`)
* **Description:** A simple yet effective counter app designed to master fundamental UI interactions.
* **Key Concepts:** State management, event handling, and basic conditional rendering.

### 2.To-do list app (`02-todo-list`)
* **Description:** A classic task management application featuring full CRUD capabilities (Create, Read, Update, Delete).
* **Key Concepts:** Managing complex array states, dynamically filtering lists, and persistence using browsers' local storage.

### 3.Weather dashboard (`03-weather-app`)
* **Description:** A dynamic dashboard that pulls real-time meteorological conditions for cities globally.
* **Key Concepts:** Fetching data from third-party REST APIs, asynchronous programming (`async/await`), and tracking loading or error UI states.

### 4.Smart notes application (`04-notes-app`)
* **Description:** A productivity tool allowing users to quickly write down, organize, and manage daily notes.
* **Key Concepts:** Component lifecycle architecture, managing multiple component states, and modern structured input styling.

### 5. GitHub user search Engine (`05-github-user-search`)
* **Description:** A profile dashboard that fetches public GitHub profile data, user statistics, and repositories instantly.
* **Key Concepts:** Fetching relational profile data, input validation handling, and advanced CSS responsive grid/flex layouts.

---

## Global tech stack

* **Core Library:** React.js (Functional Components & Hooks)
* **Build Tooling:** Vite (Fast development workflow)
* **Styling Suite:** Modern CSS3 (Variables, Flexbox, Layout Grid)
* **Data Sources:** Open-source Web REST APIs

## How to Run the Projects Locally

### 1. Clone the entire repository
```bash
git clone git@github.com:EyobaMulubrhan/React-Projects.git
cd React-Projects
```

### 2. Navigate to your project of choice
*(For example, to run the Weather App)*
```bash
cd 03-weather-app
```

### 3. Install dependencies and start the app
```bash
npm install
npm run dev
```
